# Phase 2 implementation notes

The schemas define facts independently from tax classifications. Synthetic VIES states are test labels only and are not real VAT identifiers or live results. Scenario fixtures contain expected validation/escalation metadata, not legal conclusions. Freshness classes are review triggers, not automated legal determinations.

The source registry is a curated reference list, not a complete rule database. No runtime retrieval, live VIES call, NAV API use, invoice/provider connection, tax computation, or autonomous classification exists.
