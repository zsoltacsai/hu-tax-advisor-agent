# DE source references

The canonical registry is [`sources/registry.json`](../../../sources/registry.json).
Germany-specific official entries currently include UStG §§3a, 13b, 14/14a,
18a, §4, and the BMF UStAE. Shared EU Directive provisions remain in the
shared EU source records. Each country assessment pins its chosen sources in
an immutable research snapshot; this folder does not maintain duplicate law
text.

Registry metadata records the official URL and what was accessed. The UStG
consolidated version shows the Act's last-amendment date, but cited paragraph
effective dates have not all been verified. The BMF source's exact dated
version is unknown. Those facts block execution.
